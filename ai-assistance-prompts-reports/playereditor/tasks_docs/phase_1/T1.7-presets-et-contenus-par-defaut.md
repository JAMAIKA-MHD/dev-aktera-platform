## 1. Objectif

Fournir les styles et les textes prêts à l'emploi qui donnent, dès l'ouverture du Studio, un écran complet et beau :

- 5 styles visuels ;
- les textes des 5 écrans pour chaque jeu, en français, arabe et anglais ;
- les textes du formulaire, du consentement et du bloc légal ;
- les légendes de l'accroche (teaser) de chaque jeu ;
- les 58 wilayas ;
- le registre d'icônes.

Rien de ceci n'est encore **assemblé** en configuration : c'est le rôle de T1.8 (`createDefaultExperience`). T1.7 fournit les **briques**.


## 5. Le code expliqué

### 5.1 Le registre d'icônes, coupé en deux

Une marque choisit des icônes (pastilles de lots, bloc jackpot, boîtes mystère, cible de Hit It). La configuration enregistre un **nom** (`"gift"`), jamais un composant : elle doit rester du JSON pur (règle vérifiée par `types.test.ts`).

| Fichier            | Contenu                                                      | Pourquoi ici                                                                                                                                           |
| ------------------ | ------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `domain/icons.ts`  | `ICON_NAMES = ["crown", "trophy", …] as const` et `IconName` | Le domaine doit connaître la liste pour **typer** et **valider**, mais n'a pas le droit d'importer React (règle ESLint du domaine, documentée en T0.3) |
| `presets/icons.ts` | `ICON_COMPONENTS: Record<IconName, LucideIcon>`              | Le lien avec lucide-react, utilisé plus tard par l'écran du joueur et le Studio                                                                        |

Le type `Record<IconName, LucideIcon>` oblige TypeScript à exiger un composant **pour chaque nom** : ajouter un nom sans son composant casse la compilation.

Les 16 icônes demandées par la fiche existent dans lucide-react 0.546. Une seule nuance : `help-circle` est relié à `CircleHelp`, car `HelpCircle` est un ancien nom déprécié.

Conséquences sur le domaine :

- `types.ts` : `IconName` n'est plus `string` mais l'union des 16 noms ;
- `schema.ts` : une icône inconnue (par exemple `"rocket"` dans un fichier importé) est **refusée**, puis réparée par la valeur par défaut (mécanisme de T1.6).

- **Midnight Gold** reprend le design de la capture de référence (règle D4) ; c'est le style par défaut, sombre (décision 16).
- Les deux styles clairs sont **optionnels**, comme validé.
- Les noms sont **génériques** : « Telecom Red » évoque un secteur, pas une marque. Un test l'impose (§7).

`themeFromPreset(presetId)` renvoie les réglages complets d'un style. Deux protections :

- **id inconnu** (style supprimé dans une version future, fichier modifié) → style par défaut, jamais d'erreur ;
- **copie profonde** (`structuredClone`) : si le Studio modifie la couleur renvoyée, le style d'origine reste intact.

### 5.3 Les textes par défaut (`contentDefaults.ts`)

Tous les textes existent en **français, arabe et anglais** (règle R0 : seuls les contenus vus par le joueur sont en fr/ar/en ; le code et les commentaires sont en anglais).

| Export                           | Contenu                                                                                                                                                                                                                                                                                                                                                                          |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `DEFAULT_SCREEN_CONTENT`         | Pour chaque jeu, les 5 écrans (accueil, inscription, jeu, gain, perte) : titre, sous-titre, bouton. L'**accueil** et l'écran **de jeu** sont propres à chaque jeu (« Tournez la roue et tentez votre chance », « Relevez le quiz express »…) ; inscription, gain et perte sont communs. Le gain affiche un trophée. Le quiz affiche une barre de progression, Hit It un minuteur |
| `defaultScreens(gameType)`       | Même chose pour un seul jeu (copie neuve, modifiable)                                                                                                                                                                                                                                                                                                                            |
| `STATUS_TEXT`                    | Écrans d'attente et d'état : « Préparation de votre partie… », « Déjà joué ! », « Campagne terminée », « Oups ! », « Réessayer », « Retour »                                                                                                                                                                                                                                     |
| `defaultJackpot()`               | Bloc « Grand jeu — Des lots à gagner chaque jour », icône trophée                                                                                                                                                                                                                                                                                                                |
| `defaultPrizeChips()`            | 3 pastilles : bons d'achat, cadeaux, réductions                                                                                                                                                                                                                                                                                                                                  |
| `FORM_FIELD_TEXT`                | Libellé et exemple de saisie des 4 champs (nom, téléphone `05 / 06 / 07 XX XX XX XX`, email, wilaya)                                                                                                                                                                                                                                                                             |
| `CONSENT_TEXT`                   | Consentement conforme à la loi 18-07 (§5.4)                                                                                                                                                                                                                                                                                                                                      |
| `LEGAL_LINE`                     | « Jeu gratuit sans obligation d'achat • Une participation par numéro »                                                                                                                                                                                                                                                                                                           |
| `defaultLegalLinks()`            | Liens « Règlement », « Confidentialité », « Assistance »                                                                                                                                                                                                                                                                                                                         |
| `defaultTermsBody(organisateur)` | Règlement complet, repris de la modale du prototype (§5.4)                                                                                                                                                                                                                                                                                                                       |
| `TEASER_CAPTIONS`                | Légende de l'accroche par jeu : « {count} lots à gagner », « {count} questions », « {threshold} touches en {duration} s »…                                                                                                                                                                                                                                                       |
| `QUIZ_TIMER_CAPTION`             | Ajout au quiz chronométré : « · {seconds} s chacune »                                                                                                                                                                                                                                                                                                                            |
| `LOSING_SEGMENT_LABELS`          | Segments perdants de la roue : « Dommage », « Presque ! », « Pas cette fois »                                                                                                                                                                                                                                                                                                    |
| `WHEEL_HUB_LABEL`                | Centre de la roue : « JOUER » / « العب » / « PLAY »                                                                                                                                                                                                                                                                                                                              |
| `SCRATCH_COVER_TEXT`             | Surface à gratter : « Grattez ici »                                                                                                                                                                                                                                                                                                                                              |

Les `{count}`, `{seconds}`… sont des **emplacements** que les tâches de la phase 5 rempliront avec les vraies valeurs de la campagne. `defaultJackpot`, `defaultPrizeChips` et `defaultLegalLinks` sont des **fonctions** : chaque appel renvoie une copie neuve. Leurs éléments n'ont pas encore d'`id` : T1.8 les ajoutera en assemblant la configuration.

### 5.4 Ce qui a été changé par rapport au prototype

Le prototype a servi de base, mais plusieurs de ses textes violent nos règles. Ils ont été **réécrits**, pas copiés :

| Texte du prototype                             | Problème                                                          | Remplacé par                                                                                                                                     |
| ---------------------------------------------- | ----------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| « Gain garanti », « 100 % gagnant »            | Promesse de gain (règle B8) : le tirage est décidé par le serveur | Aucun texte ne promet de gagner                                                                                                                  |
| « Une des 3 boîtes cache le jackpot »          | Laisse croire que le choix de la boîte compte (B8)                | « Trois boîtes, un seul choix : laquelle ouvrirez-vous ? »                                                                                       |
| « +1 essai » en partageant                     | Bonus de partage interdit (N4, décision 6)                        | Supprimé                                                                                                                                         |
| Consentement « SMS » et « données certifiées » | Ne couvre pas le traitement des données (loi 18-07)               | « J'accepte le règlement du jeu et le traitement de mes données personnelles pour la gestion de ma participation, conformément à la loi 18-07. » |
| « Valable 48 h »                               | Durée inventée, non garantie par le serveur                       | Supprimé                                                                                                                                         |
| Segment perdant « Rejouez »                    | Faux : une seule participation par numéro                         | « Pas cette fois »                                                                                                                               |

Le **règlement** (`defaultTermsBody`) reprend la structure de la modale du prototype : organisateur, gratuité, une participation par numéro, tirage sécurisé dans la limite des stocks, usage des données et droits d'accès, de rectification et d'opposition (loi 18-07). Si le nom de l'organisateur est vide, la phrase devient « organisée par l'organisateur de cette campagne », jamais « organisée par » suivi d'un blanc.

### 5.5 Les wilayas (`wilayas.ts`)

La liste est **générée** depuis `src/components/player-editor/aktera-i18n.ts` (source désignée par la fiche), pas retapée : 58 entrées `{ code, nameFr, nameAr }`, de « 01 Adrar / أدرار » à « 58 El Meniaa / المنيعة ».

`wilayaLabel(wilaya, langue)` donne l'étiquette affichée dans la liste déroulante : « 16 - Alger » en français et en anglais, « 16 - الجزائر العاصمة » en arabe.

## 6. Décisions et alternatives

| Décision                                                              | Alternative écartée                                     | Raison                                                                        |
| --------------------------------------------------------------------- | ------------------------------------------------------- | ----------------------------------------------------------------------------- |
| Noms d'icônes dans `domain/`, composants dans `presets/`              | Tout dans `presets/icons.ts`, comme le suggère la fiche | Le domaine a besoin de la liste pour typer et valider, sans importer React    |
| Textes réécrits quand le prototype enfreint une règle (§5.4)          | Copie fidèle                                            | Règles B8, N4 et loi 18-07 prioritaires sur la reprise du prototype           |
| « Pas cette fois » au lieu de « Rejouez », pourtant cité par la fiche | Garder l'exemple de la fiche                            | « Rejouez » est faux avec une participation par numéro                        |
| Wilayas générées depuis la source                                     | Liste retapée à la main                                 | Pas d'erreur de recopie sur 58 × 2 noms                                       |
| Fonctions (`defaultJackpot()`…) pour les objets modifiables           | Constantes partagées                                    | Une modification dans le Studio ne doit jamais altérer les valeurs par défaut |

## 9. Écarts, imprévus et points d'attention

- **Registre coupé en deux** (§5.1) : un fichier de plus que la fiche, `domain/icons.ts`.
- **Textes du prototype réécrits** (§5.4), dont l'exemple « Rejouez » cité par la fiche.
- **Écrans d'état non modifiables par la marque** : `STATUS_TEXT` est fixe, comme prévu par `ScreenKey` (T1.4). À rediscuter si une marque veut son propre « Déjà joué ».
- **58 wilayas**, conformément à la source. Si le découpage administratif a changé depuis, il faudra mettre la liste à jour.
- **Correction d'un chiffre dans la documentation de T1.6** : `schema.test.ts` contenait 40 tests, et non 41 comme écrit alors.
- **Les textes arabes** ont été rédigés avec soin, mais une relecture par un arabophone natif est recommandée avant la mise en production.
