## 5. Le code expliqué

### 5.1 Legal

- **Organizer name** (`legal.organizerName`), nommé dans le texte légal.
- **Footer links** : `ListEditor` de 0 à 5 liens ; pour chacun, le type (Game rules, Privacy, Support, Other link), le libellé en trois langues (obligatoire) et l'adresse. **Seuls `https:`, `mailto:` et `tel:` sont acceptés** : une autre adresse déclenche l'erreur `link-url:<n>` (T1.11), affichée en tête de la carte. Adresse vidée ⇒ la clé `url` disparaît et le lien ouvre le texte légal (règle de `legalLinkTarget`, rappelée par le placeholder « Empty: opens the legal text ») ; un « Other link » sans adresse est une erreur.
- **Mentions** : mention courte (le bandeau défilant de l'accueil, 120 caractères) et texte légal complet (multiligne), en trois langues.

### 5.2 Export et import (`shareFile.ts`)

- **`exportFileName(name, date)`** : `player-experience-rentree-zeta-2026-09-23.json` — minuscules, accents retirés, tirets seulement ; `standalone` sans campagne ; `campaign` si le nom n'a aucun caractère latin.
- **`downloadJson`** : `Blob` + lien temporaire, la logique de `MAKER/utils/exportImport.ts` (un `Blob` plutôt qu'une URL `data:`, sans limite de taille).
- **`readImportedConfig(text)`** : JSON illisible → « This file is not valid JSON. » ; sinon `parseExperienceConfig` (migrations comprises). **Si le schéma a dû réparer quoi que ce soit, l'import est refusé** — « This file is not a Player Experience configuration, or it is damaged. Nothing was changed. » — avec jusqu'à cinq raisons (`theme.mode: …`). Réparer en silence ferait croire à la marque qu'elle a importé son fichier alors qu'une partie a été remplacée par des valeurs par défaut.

### 5.3 Share

- **Export JSON** : désactivé tant qu'une **erreur bloquante** existe, avec « Fix required issues before sharing. » (la même règle que le panneau de validation, T6.8).
- **Import JSON** : fichier de 5 Mo au plus ; refus affiché (`role="alert"`) sans toucher à rien ; succès = `replaceConfig`, donc **un seul pas d'historique**, et l'identité de la configuration éditée (`id`, `campaignId`) est conservée : l'import s'enregistre là où vit cette campagne. Le message le rappelle : « Undo (Ctrl+Z) brings the previous version back. »
- **Reset demo data** : `resetDemoEntries(campaignId)` efface les participations de démo de cette campagne (ou de la campagne de démo) : chaque numéro peut rejouer dans l'aperçu. Les vraies participations ne sont jamais concernées (N4 reste entier côté serveur).
- **Rappel** : « This experience is saved in this browser only. Export it to keep a copy or to move it to another computer. » (décision n° 2, `localStorage` uniquement.)

## 6. Décisions et alternatives

| Décision                                                        | Alternative écartée                        | Raison                                                                   |
| --------------------------------------------------------------- | ------------------------------------------ | ------------------------------------------------------------------------ |
| Import refusé dès que le schéma doit réparer                    | Accepter la version réparée                | Critère : « refusé avec un message clair et sans casser l'état courant » |
| Import = `replaceConfig` (un pas d'annulation, identité gardée) | Remplacer aussi `id` et `campaignId`       | Sinon l'autosave écrirait sous la clé d'une autre campagne               |
| Export désactivé en cas d'erreur bloquante                      | Exporter quand même                        | Un fichier partagé doit être jouable ; T6.8 applique la même règle       |
| `resetDemoEntries` exposé par la racine de composition          | Importer `services/local` depuis le Studio | Le Studio ne dépend pas des adaptateurs concrets (règles d'architecture) |
