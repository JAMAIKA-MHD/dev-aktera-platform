## 1. Objectif

Les textes de l'expérience : **Content** édite ce que dit chaque écran (Welcome, Register, Play, Win, Lose), dans les trois langues, et les langues proposées aux joueurs ; **Sections** règle les deux blocs facultatifs de l'accueil qui mettent les lots en avant — la carte jackpot et les étiquettes de lots (1 à 4). Un texte modifié apparaît dans l'aperçu, dans la bonne langue, sans rechargement.

## 2. Où elle se situe

- S'appuie sur : les champs (T6.3), les pièces communes des panneaux (T6.4 : `PanelLayout`, `useTextLocale`, `useRevealFocusPath`), le store (`updateScreen`, `updateSection`, `updateConfig`, T6.1), le pont d'aperçu (T6.2).
- Les chemins des champs (`screens.win.title`, `sections.prizeChips.items.2.value`…) sont ceux des contrôles de conception (T1.11) et des `data-xp-edit` du runtime (T3.4 à T3.6) : un problème ou un clic dans l'aperçu mène au bon champ.

## 5. Le code expliqué

### 5.1 Content — un seul écran à la fois, le même que l'aperçu

L'écran édité et l'écran montré sont le même, dans les trois sens :

```ts
const pick = (next: ScreenKey) => {
  setKey(next);
  setScreen(next);
}; // le panneau → l'aperçu
useEffect(() => {
  if (isScreenKey(previewScreen)) setKey(previewScreen);
}, [previewScreen]); // l'onglet de l'aperçu → le panneau
useEffect(() => {
  /* "screens.play.title" → "play" */
}, [focusPath]); // un clic sur un texte de l'aperçu → le panneau
```

C'est le critère de la fiche « cliquer sur un écran dans l'aperçu ouvre l'écran correspondant dans ce panneau » : un clic sur le titre de l'accueil ouvre Content, sur l'écran Welcome, avec le focus dans le champ Titre (vérifié dans Chrome).

Pour l'écran choisi :

| Carte               | Champs                                                                                                                                                                                            |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Texts**           | Titre (compteur `TITLE_MAX_CHARS` = 60, « deux lignes au plus sur un petit téléphone ») ; sous-titre (multiligne, 140) ; bouton principal (28) ; bouton secondaire (interrupteur, puis son texte) |
| **Around the text** | En-tête affiché ou non ; visuel au-dessus du titre (None, Badge, Trophy, Gift, Timer) ; encouragement (aucun, essais restants, temps restant, progression, indice) et son texte                   |
| **Languages**       | voir 5.2                                                                                                                                                                                          |

Tous les textes sont des `LocalizedTextField` reliés à la langue de l'aperçu (`useTextLocale`, T6.4) : cliquer l'onglet **AR** d'un champ passe l'aperçu en arabe, et ce qu'on tape s'y affiche de droite à gauche. Les problèmes de l'écran (titre trop long, traduction manquante, promesse de gain) sont listés en tête de la carte Texts.

### 5.2 Langues

- Un interrupteur par langue (français, arabe, anglais), toujours dans cet ordre quel que soit l'ordre des clics.
- **La langue par défaut ne peut pas être désactivée** (interrupteur verrouillé, infobulle « The default language is always offered ») : c'est le repli de toute traduction manquante, et le schéma l'exige.
- La langue par défaut se choisit parmi les langues activées.
- Si l'aperçu était dans une langue qu'on vient de retirer, il revient à la langue par défaut.

### 5.3 Sections

- **Carte jackpot** : interrupteur ; petit titre (24), texte principal (48), badge (14, vide = pas de badge), icône. Les champs disparaissent quand la carte est masquée.
- **Étiquettes de lots** : interrupteur, puis un `ListEditor` borné à **1 à 4** (`MIN_CHIPS`, `MAX_CHIPS`) — « Add a chip » devient « Maximum 4 », la dernière étiquette ne peut pas être retirée. Chaque étiquette : valeur (16, avec un exemple en placeholder dans chaque langue), légende (24), icône, couleur (Primary, Secondary, Accent). Une nouvelle étiquette reçoit un identifiant UUID.
- Rappel en tête de fichier : ces blocs sont de la **présentation** ; ce que le joueur peut gagner est décidé par la campagne (B1).

## 6. Décisions et alternatives

| Décision                                            | Alternative écartée                        | Raison                                                                                      |
| --------------------------------------------------- | ------------------------------------------ | ------------------------------------------------------------------------------------------- |
| L'écran du panneau suit l'aperçu et inversement     | Un sélecteur d'écran propre au panneau     | La marque voit toujours ce qu'elle édite                                                    |
| L'écran visé par un clic est lu dans `ui.focusPath` | Changer l'écran de l'aperçu depuis le pont | Le clic vient de l'aperçu, qui montre déjà cet écran ; relancer le parcours l'interromprait |
| Langue par défaut verrouillée                       | La laisser désactivable avec une erreur    | Impossible par construction plutôt que signalé après coup                                   |
| Icône et couleur d'une étiquette l'une sous l'autre | Sur une même ligne (première version)      | Débordait de la carte dans la largeur du panneau (vu dans Chrome)                           |
| `ToggleField` nommé par son seul libellé            | Nom = libellé + description                | Deux interrupteurs dont les descriptions se ressemblaient avaient des noms ambigus          |
