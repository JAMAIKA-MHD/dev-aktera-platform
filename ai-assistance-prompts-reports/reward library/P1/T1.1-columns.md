## Objectif

Poser les trois colonnes sans changer le comportement de l'existant. Crée le fichier de migration unique de l'issue.

## Fichiers concernés

- `supabase/migrations/<timestamp>_reward_expiry_and_delivery.sql (nouveau)`

## Étapes

1. Créer la migration avec un horodatage postérieur à `20260929160000`.
2. `ALTER TABLE public.prize_template_items ADD COLUMN IF NOT EXISTS expires_at timestamptz;` (nullable : `NULL` = n'expire jamais).
3. `ALTER TABLE public.entries ADD COLUMN IF NOT EXISTS delivery_status text NOT NULL DEFAULT 'not_delivered' CHECK (delivery_status IN ('not_delivered','delivered'));`
4. `ALTER TABLE public.entries ADD COLUMN IF NOT EXISTS delivered_at timestamptz;`
5. Vérifier si `idx_prize_template_items_available` suffit pour le filtre de disponibilité ; sinon ajouter un index minimal (`CREATE INDEX IF NOT EXISTS`).
6. Ne rien supprimer, ne rien renommer, aucun `GRANT`.

## Vérification

`npx supabase db reset` sans erreur ; `\d prize_template_items` et `\d entries` montrent les colonnes ; les lignes existantes ont `delivery_status = 'not_delivered'`.
