## Objectif

Tests exécutables qui prouvent les règles de la base (expiration, concurrence, épuisement, livraison).

## Fichiers concernés

- `scripts/probe-rewards.sql (nouveau) ou intégration à `scripts/`du`backend:probe``

## Étapes

1. Préparer un jeu de données minimal (organisation, deux utilisateurs dont un `viewer`, campagne, lot, entrées) et nettoyer après.
2. Cas : code expiré + valide → valide ; seul expiré → rien ; deux attributions concurrentes (deux sessions) → deux codes distincts ; lot épuisé jamais tiré sur ≥ 200 tirages ; lot sans code toujours éligible.
3. Cas livraison : membre OK ; `viewer` refusé ; autre organisation refusée ; entrée perdante refusée ; lot numérique refusé ; `anon` refusé.
4. Chaque cas affiche `PASS`/`FAIL` et le script retourne un code de sortie non nul au moindre échec. Documenter la commande d'exécution en tête du fichier.

## Vérification
